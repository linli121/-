# LiQing の 宝藏之地 🏝️

一个纯前端实现的个人博客网站，采用 **HTML5 + CSS3 + 原生 JavaScript** 编写，**零依赖、无需构建工具**。拥有毛玻璃质感、流萤 / 樱花粒子背景、跨页面时间同步的背景轮播、慢速弹幕引擎、昼夜主题切换以及照片墙画廊等丰富的视觉与交互效果。

> 你好，我是 LiQing，一名人工智能专业的大一学生，热爱编程与人工智能领域。这里是我的个人小站。

## 🚀 快速开始

本项目为纯静态站点，无需安装任何依赖或运行构建命令。

### 方式一：直接双击打开

直接用浏览器打开 `index.html` 即可。

### 方式二：使用本地静态服务器（推荐）

某些浏览器对 `localStorage` 和本地资源在 `file://` 协议下有安全限制，建议使用任意静态服务器启动：

```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js（npx）
npx serve .
```

然后在浏览器访问 `http://localhost:8000`。

## 🛠️ 自定义指南

代码中标注了大量 `↙↙↙ 【在此处修改...】` 注释，便于快速定位修改点。

### 1. 修改背景轮播图片

编辑 `shared-bg.js` 顶部的 `bgImages` 数组：

```js
const bgImages = [
    "./img/自拍.png",
    "./img/今汐.jpg",
    "./img/今汐新年.jpg",
    "./img/芙芙.jpg",
    "./img/月下.jpg"
];
```

### 2. 修改弹幕词库

编辑 `shared-bg.js` 中的 `defaultDanmakus` 数组，加入你喜欢的词条。

### 3. 修改照片墙相册

编辑 `gallery.html` 底部脚本中的 `albumsData` 数组，每个相册支持 `title`、`date`、`desc`、`aspect`（`landscape` / `portrait`）和 `photos` 字段。

### 4. 修改主题配色

编辑 `theme.css`，`:root` 为日间变量，`:root.dark` 为夜间变量。

### 5. 修改首页轮播内容

在 `index.html` 中搜索「幻灯片」注释，替换对应的背景图路径、标题、日期与描述。
